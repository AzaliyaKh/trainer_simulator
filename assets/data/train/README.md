## Test Dataset

The test dataset is based on a large industrial pump maintenance dataset. It contains pump sensor measurements such as temperature, pressure, RPM, vibration, flow rate, operational hours, and a maintenance flag. In this project, the dataset is used to test the trained regression model on a separate pump-related dataset by predicting vibration from temperature, pressure, and RPM.

Dataset: https://www.kaggle.com/datasets/selonamaris/large-industrial-pump-maintenance-dataset/data
