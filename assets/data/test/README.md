## Training Dataset

The training dataset is based on an industrial predictive maintenance dataset for petrochemical equipment. It contains sensor measurements such as temperature, pressure, RPM, current, and vibration values along three axes. In this project, the dataset is used to train a regression model that predicts overall vibration from temperature, pressure, and RPM.

Source article / notebook: https://www.kaggle.com/code/abbat108/petrochem
Dataset: https://www.kaggle.com/datasets/programmer3/petrochemical-predictive-maintenance-dataset/data
